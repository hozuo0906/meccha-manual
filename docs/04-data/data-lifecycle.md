# データライフサイクル

Status: Accepted

## 保持方針

| データ | 既定保持 | 方針 |
|---|---|---|
| 手順書公開版 | ワークスペース契約中 | 正本として保持 |
| 下書き | ワークスペース設定 | 履歴数または日数で整理 |
| 記録イベント | ワークスペース設定 | 下書き生成後も監査/復旧範囲で保持 |
| スクリーンショット | ワークスペース設定 | 削除時は派生画像も対象 |
| 共有リンク | 期限または失効まで | tokenはhashのみ保存 |
| 閲覧分析 | ワークスペース設定 | 集計値と生イベントを分ける |
| 監査ログ | 長期保持 | 更新削除禁止 |
| Stripeイベント | 法務/会計要件に合わせて長期 | 生payloadではなくdigestを基本にする |
| 都度払いの再出力権 | 購入日から30日 | 対象manualのエクスポート権だけ失効し、manual本体を自動削除しない |

## 削除

- 手順書削除は原則アーカイブから始める。
- 完全削除は画像、派生ファイル、共有リンク、分析、コメントへの影響を明示する。
- 退会後削除猶予は未決事項として管理する。
- 未契約作成枠の下書き、操作記録画像、都度払い購入後データの保持期間はOQ-023で決める。
- 都度払いの返金や再出力期限切れを、手順書や画像の即時物理削除へ直結させない。

## 個人情報

スクリーンショットには個人情報が写り得ます。公開前の機密情報確認とマスキングを必須にします。
