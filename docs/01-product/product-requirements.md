# 機能要件

Status: Accepted

## プロダクト原則

- 主役は文書ではなく、業務を完了できる手順。
- 情報構造は `ワークスペース -> フォルダー -> 手順書` の3階層を基本とする。
- 公開URLは正式な共有正本。PDFは補助出口。
- 操作記録の第一方式はCloudflare Browser Run + Live View。
- 初期状態で外部AI APIを呼ばない。
- 外部AI機能は収益が安定するまで実装工程の最後尾に置き、コア機能の成立条件にしない。
- AIがなくても手順書の作成、編集、記録、画像、共有、export、分析まで利用できる設計を維持する。
- Browser RunやR2のように利用量が原価へ直結する機能は、決済機能より先であってもサーバー側利用上限を同時に実装し、無制限利用を許可しない。

## 要件

| ID | 要件 | 受入条件 |
|---|---|---|
| FR-001 | ユーザーはSupabase Authでログインできる | ログイン、ログアウト、期限切れ、再ログインが動作する |
| FR-002 | ユーザーは必ずワークスペースに所属する | 個人単独利用のデータが作られない |
| FR-003 | owner/admin/editor/viewerを管理できる | 権限ごとのCRUDがAPIとRLSで制御される |
| FR-004 | 手順書を作成、編集、削除、アーカイブできる | 下書きと公開版が混ざらない |
| FR-005 | 手順を追加、並べ替え、削除できる | 1手順1操作の構造を維持できる |
| FR-006 | 日本語テンプレ文を生成できる | `［対象］を［操作］します` 形式で生成される |
| FR-007 | Cloudflare Browser Runで対象URLを開ける | Live View URLを短命で発行できる |
| FR-008 | 操作イベントを記録できる | クリック、入力完了、遷移、スクロールが連番で保存される |
| FR-009 | スクリーンショットを保存できる | private R2 bucketへ保存され、短期署名URL経由で閲覧する |
| FR-010 | 入力値を原則保存しない | password、カード番号、トークン、個人番号が保存されない |
| FR-011 | 操作記録から下書きを生成できる | 記録終了後、手順書エディタで編集できる |
| FR-012 | 共有リンクを作成できる | デフォルトOFF、期限、パスコード、無効化がある |
| FR-013 | 未ログイン閲覧ができる | 公開許可された共有リンクのみ閲覧できる |
| FR-014 | PDF/Markdown/HTML出力ができる | 日本語、画像、ぼかし、リンクが維持される |
| FR-015 | Guide Me風の再生ができる | 対象不一致時は停止し、勝手に進まない |
| FR-016 | スマホ表示確認ができる | UA、viewport、DPR、touch、colorSchemeを設定できる |
| FR-017 | 閲覧分析を記録できる | 閲覧数、完了率、離脱ステップを原イベントから集計できる |
| FR-018 | コメントと古い情報の報告ができる | 手順単位で管理者に通知される |
| FR-019 | 短命なStripe Checkout SessionとStripe Linkで購入できる | 課金確定は署名検証済みWebhookのみで、Linkの利用者情報をアプリ認証に使わない |
| FR-020 | AI拡張口を持つ | 収益安定後にユーザーが明示承認するまで実装せず、外部AI APIを呼ばない |
| FR-021 | 都度払い、パーソナル、チームの利用権と上限を適用できる | 対象マニュアル、席数、Browser Run時間、保存容量、同時記録数がサーバー側で検証される |

## 実装優先順位

1. 手順書コア（FR-004 / FR-005 / FR-006）
2. Browser Run操作記録（FR-007 / FR-008 / FR-010 / FR-011 / FR-016）
3. スクリーンショット・画像管理（FR-009）
4. 公開・共有（FR-012 / FR-013）
5. export・再生（FR-014 / FR-015）
6. 閲覧分析・コメント・古い情報の報告（FR-017 / FR-018）
7. AI拡張（FR-020）— 収益が安定してから再評価する

課金導線（FR-019）は事業上の公開条件に合わせて別途進める。ただし、FR-021のうち原価を守るための利用上限は後回しにしない。Browser Runを有効化する前に時間・同時記録数を、R2書込を有効化する前に保存容量をサーバー側でfail closedに制御する。上限値や計測条件が未確定なら、対象の有料原価機能を無制限で有効化せず停止側へ倒す。

## 重要な制約

- Cloudflare Browser Runは常に対象サイトからbotとして識別される可能性がある。
- IP制限、社内DNS、端末認証、ハードウェアキー、bot対策があるサイトは利用できない可能性がある。
- スマホ表示確認はChrome相当の確認であり、実機保証ではない。
- 課金上限到達時に自動従量課金せず、追加利用を停止して日本語で次の操作を案内する。
- FR-006は外部AI APIを使わず、決定的なローカルテンプレート処理を基本とする。
- FR-020は収益が安定したとユーザーが判断し、価値・概算コスト・月額上限・停止条件を確認して実装開始を明示承認するまで、adapter、feature flag、API key、runtime callを含め実装しない。
