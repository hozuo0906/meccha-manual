# スコープ

Status: Accepted

## 全体方針

設計は全部入りで持ちます。ただし開発は段階的に進めます。各Phaseの品質ゲートを通過した機能だけ次に進めます。

## 全体スコープ

- 認証、ワークスペース、権限
- 手順書作成、編集、版管理
- システム内クラウドブラウザによる操作記録
- 共有リンク、埋め込み、PDF/Markdown/HTML出力
- Guide Me風の操作案内
- スマホ表示確認
- 分析、コメント、通知、監査ログ
- Stripe Checkout SessionsとLinkによる課金拡張
- owner承認後に別途スコープ化するAI拡張（現スコープでは設計・実装しない）
- 品質ゲート、レビューloop、Runbook

## 初回公開の考え方

初回公開に全機能を無理に同時投入しません。設計とデータ構造は全部入りで持ち、公開は品質ゲートを通った機能単位で行います。

## 明示的非対象

- Chrome拡張必須の体験
- bot保護回避
- 社内intranetへの万能アクセス保証
- ネイティブアプリ記録
- 実機Safari/Android OS完全再現
- 売上安定の確認とowner明示承認前のAI設計・実装・設定・外部API呼び出し
