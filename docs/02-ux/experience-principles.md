# UX原則

Status: Accepted

## 基本方針

`めっちゃマニュアル` はWikiではありません。操作を記録し、業務手順として確認、公開、更新するための作業台です。

## 画面原則

- 一覧は表を基本にする。
- 手順書閲覧は縦スクロールを基本にする。
- エディタは左に手順一覧、中央に画像、右に編集パネルの3ペインを基本にする。
- 設定はフォームで扱う。
- 何でもカードにしない。
- 公開閲覧画面に管理画面用ナビゲーションを出さない。

## 文言

- 丁寧だが短い `です・ます` 調。
- 英語やカタカナの多用を避ける。
- ボタンは行動を明示する。例: `作成` ではなく `手順書を作成`。
- エラーは `何が起きたか -> どこまで保存されたか -> 次に何をするか` の順に書く。

## 状態

各画面で以下の状態を設計する。

- 空
- 読込中
- 保存中
- 保存済み
- 保存失敗
- 権限不足
- 接続切断
- 期限切れ
- 容量超過

## アクセシビリティ

- 色だけで状態を伝えない。
- ドラッグ操作にはボタン操作の代替を用意する。
- アイコンボタンにはツールチップとアクセシブル名を付ける。
- 本文16px以上、一覧14px以上、タッチ対象44px以上を目安にする。
