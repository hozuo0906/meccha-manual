# プロジェクト憲章

Status: Accepted

## 目的

日本人オフィスワーカーが、業務システムの操作手順を短時間で記録し、スクリーンショット付きの手順書として編集、共有、更新、分析できるサービスを作る。

## 解決する問題

- マニュアル作成に時間がかかる。
- スクリーンショット、注釈、説明文が属人化する。
- 更新された手順がPDFや社内チャットに散らばる。
- 手順が古くなったことに気づけない。
- スマホ表示確認や操作確認を別ツールで行う必要がある。

## 成功指標

- オフィスワーカーが説明なしで `操作を記録 -> 編集 -> 共有` まで完了できる。
- 手順書の公開URLを業務共有の正本にできる。
- 非公開情報が共有リンク、Storage、分析、ログから漏れない。
- P0/P1が0件の状態で段階リリースできる。

## 固定前提

- 対象は日本人オフィスワーカー。
- UIは日本語専用。
- Cloudflare Pages/Workers、Cloudflare Browser Run、Supabase、Stripeを前提にする。
- 初期はAI APIを呼ばない。
- Chrome拡張は第一方式にしない。
- GitHub Codespacesを開発場所の第一候補にする。

## 非目標

- bot保護の回避。
- localhostや社内intranetへの万能アクセス保証。
- ネイティブアプリ操作の記録。
- 実機SafariやAndroid OSの完全再現。
- TangoやMobile Simulatorのコード、文言、ロゴ、画像資産のコピー。
