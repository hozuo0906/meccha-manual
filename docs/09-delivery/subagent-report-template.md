## 現行の独立タスク契約

このファイル名と以下の観点名は、既存CI／PRテンプレートとの互換性のため維持する。専任6サブエージェントや6個の別taskを必須にせず、現行はAstra high親PMが要件・統合判断・品質ゲートを担い、Luna high作業担当が限定範囲の実装・検証・報告を担う。対象観点は作業担当が確認し、親PMが実証照合する。作業担当はサブエージェントを使わず、次taskを自己増殖させない。起動形態の正本はDEC-066と`docs/09-delivery/decision-log.md`／`session-handoff.md`であり、本templateは記録形式を定めるだけで品質ゲートを弱めない。
