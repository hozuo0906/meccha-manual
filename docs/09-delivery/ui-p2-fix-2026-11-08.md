## 再現条件と変更点

- 初回一覧GETを503で失敗させ、フォーカスした「もう一度読み込む」をEnterで実行し、再取得も503にする。`loadManuals`冒頭の`list.replaceChildren`で旧ボタンが切断され、再失敗後の新ボタンにフォーカスが戻らない。修正前の追加ブラウザ回帰は、このフォーカスassertionで失敗した。
- `loadManuals`開始時に`document.activeElement`と一覧内にあったかを記録する。再失敗で再試行ボタンを描画した後、現在のフォーカスが未設定・body・元要素の場合だけ、新ボタンへ`preventScroll`付きで復帰する。既存popupの`withBusy`の`hadFocus`／`focusUnclaimed`パターンに揃えた。
- 初回失敗での自動focus移動は追加せず、応答待ち中に検索欄へ移った場合はそのfocusを維持する。既存request serialの応答破棄条件を保持する。API・認証・共有・DB・権限・依存・envの変更はない。
- UX契約・トレーサビリティ・decision-logを同期した。7assetの既存回帰と同じ順序・NUL区切りでSHA-256を再計算し、`APP_ASSET_VERSION`を`sha256-0b149ba73aa80f8a`へ更新した。
