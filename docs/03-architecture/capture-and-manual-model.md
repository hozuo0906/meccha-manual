# 操作記録と手順書モデル

Status: Accepted

## モデル

- `manuals`: 手順書の論理エンティティ。
- `manual_revisions`: 下書きと公開版。
- `manual_steps`: 手順。
- `capture_sessions`: 操作記録セッション。
- `capture_events`: 操作イベント。
- `assets`: スクリーンショットや出力ファイル。

## 版管理

- 公開版は不変。
- 編集は下書きに対して行う。
- 公開時に不変の `manual_revisions` を作る。
- 共有リンクは公開版を参照する。

## 手順文生成

初期はAI APIを使わず、DOMターゲットと操作種別から日本語テンプレ文を作る。

例:

- `［保存］を選択します`
- `［メールアドレス］欄に入力します`
- `［次へ］を選択します`

## マスキング

- password inputは常に対象。
- カード番号、トークン、個人番号候補は検出対象。
- 画像内の繰り返し氏名/メールアドレスは一括ぼかし候補にする。
- 公開前に機密情報確認を必須にする。
