# ADR-0009: AI APIは収益安定後まで実装しない

Status: Accepted

## 決定

外部AI APIを使う機能は、収益が安定したとユーザーが判断し、利用価値、概算コスト、月額上限、停止条件、送信データ境界を確認したうえで実装開始を明示承認するまで実装しない。

手順文はDOMターゲットと操作種別から決定的な日本語テンプレートで生成し、AIがなくても手順書の作成、編集、操作記録、画像、共有、export、分析まで成立させる。

収益安定前は、管理者がAIをONにする経路も提供しない。AI専用adapter、feature flag、API key/Secret、runtime call、利用ログ基盤を先行実装しない。将来の一般的な拡張性を理由に、AI専用依存をコア機能へ持ち込まない。

## 理由

外部AI APIは従量課金で、利用量に応じてサービス運営者へ請求が発生する。また、スクリーンショットやDOMには機密情報が含まれる可能性がある。収益化前に固定費・従量費・データ送信範囲を増やさず、まずAIなしで価値を検証する。

## 再評価条件

次をすべて満たした場合だけ、FR-020の実装計画を再開する。

- ユーザーが収益は安定したと判断する。
- AIで増える利用価値と、想定API費用を比較できる。
- 月額上限、利用停止条件、異常利用時のkill switchを設計する。
- 外部送信するデータとマスキング境界を確認する。
- ユーザーが実装開始を明示承認する。

再評価時はこのADRを更新し、新しい実装範囲・費用上限・データ境界をAcceptedにしてから着手する。

## 影響

- FR-006はローカルテンプレート生成で実装する。
- AI未設定をエラー扱いにせず、基本機能は常にAIなしで動作する。
- 収益安定前はAI APIキーをCloudflare SecretやGitHub Secretへ登録しない。
- 管理者ON/OFFのUI/APIを収益安定前に実装しない。
- AIのためだけのDBテーブル、利用ログ、課金計測を先行追加しない。
